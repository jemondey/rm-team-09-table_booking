# UC-bkdep-02. Отменить приход гостей
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Хостес                                                          |
| Другие действующие лица  | Гость                                                           |
| Предусловия              | Есть бронь на текущий вечер                                     |
 
## Основной сценарий
1. Гость приходит и называет имя.
2. Хостес находит бронь в списке.
3. Хостес нажимает кнопку подтверждения.
4. Система меняет статус брони.
 
## Альтернативные сценарии
1а. Гость опоздал менее чем на 15 минут: хостес отмечает приход, система меняет статус, столик удерживается.
 
## Исключения
1а. Опоздание более чем на 15 минут: система автоматически переводит бронь в статус «Неявка» и освобождает столик для других гостей, депозит остается у ресторана.

## Успех
Столик находится в статусе «Занят».

## Неуспех
Столик свободен для бронирования.
