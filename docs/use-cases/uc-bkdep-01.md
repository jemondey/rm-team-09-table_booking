# UC-bkdep-01. Забронировать столик для компании с депозитом
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Гость                                                           |
| Другие действующие лица  | Платежный сервис, SMS-шлюз, кассовая система                    |
| Предусловия              | Ресторан и время выбраны, в брони 6 гостей или больше           |
 
## Основной сценарий
1. Гость выбирает ресторан, дату, время, столик, количество гостей.
2. Система информирует о депозите
3. Гость подтверждает бронь.
4. Гостя перенаправляют на оплату.
5. Гость успешно оплачивает депозит.
6. Бронь фиксируется, принимает статус «Оплачено», деньги отправляются в кассовую систему.
7. Система отправляет SMS-подтверждение гостю.
8. Гость получает подтверждение и уникальный номер брони на экране.
 
## Альтернативные сценарии
1а. Отмена брони: депозит возвращается, система снимает бронь со стола.
 
## Исключения
5а. Оплата не прошла: система уведомляет гостя, происходит повторная оплата.
5б. Стол занят: оплата не ппроходит, деньги остаются у гостя, система предлагает выбрать другой стол.
