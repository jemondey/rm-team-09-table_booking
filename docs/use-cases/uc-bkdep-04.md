# UC-bkdep-04. Забронировать столик по телефону 
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Хостес                                                          |
| Другие действующие лица  | Гость (по телефону)                                             |
| Предусловия              | Есть свободный столик на запрашиваемое время                    |
 
## Основной сценарий
1. Гость звонит в ресторан.
2. Хостес открывает экран создания новой брони.
3. Хостес вводит ФИО, телефон, дату, время и количество гостей.
4. Хостес выбирает подходящий столик на схеме.
5. Система проверяет отсутствие накладок.
6. Хостес сохраняет бронь.
7. Система отправляет SMS гостю.
 
## Альтернативные сценарии
4а. Нет столика нужного размера на это время. Хостес предлагает другой столик на другое время.

## Исключения
6а. Сбой системы при сохранении. Хостес записывает данные на бумагу, чтобы внести их позже, и извиняется.

## Успех
Бронь создана, столик занят, гость получил SMS.

## Неуспех
Бронь не создана, столик свободен, гость не получил подтверждение.
