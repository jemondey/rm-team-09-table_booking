# UC-bkdep-03. Изменить схему зала и столиков
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Управляющий                                                     |
| Другие действующие лица  | Нет                                                             |
| Предусловия              | Управляющий авторизирован в системе под своей ролью             |
 
## Основной сценарий
1. Управляющий открывает раздел «Схема зала».
2. Выбирает режим редактирования.
3. Перетаскивает столики, меняет их размеры.
4. Нажимает «Сохранить изменения».
 
## Альтернативные сценарии
3а. Управляющий объединяет два столика в один для большой компании.

## Исключения
3а. Управляющий пытается удалить столик, на который уже есть активные брони на будущие даты. Система блокирует действие и выдает предупреждение.

## Успех
Новая схема зала сохранена и отображается предпросмотр.

## Неуспех
Изменения не сохранены, схема остается прежней, управляющий видит сообщение об ошибке.
