# UC-bkdep-05. Отмена брони и возврат депозита
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Гость                                                           |
| Другие действующие лица  | Платежная система                                               |
| Предусловия              | У гостя есть активное бронирование.                             |
|                          | Гость внес депозит при бронировании.                            |
 
## Основной сценарий
1. Гость открывает информацию о своем бронировании.
2. Выбирает действие «Отменить бронирование».
3. Система проверяет условия отмены и возврата депозита.
4. Система показывает сумму, доступную к возврату.
5. Гость подтверждает отмену.
6. Система меняет статус брони на «Отменена».
7. Система отправляет запрос на возврат через платежную систему.
8. Гость получает SMS об отмене и информацию о возврате.
 
## Альтернативные сценарии
1а. Гость отказывается от отмены бронирования после просмотра суммы возврата. Бронь остается активной.
3а. Срок бесплатной отмены истек. Система предупреждает гостя, что депозит не будет возвращен, и предлагает подтвердить отмену.

## Исключения
7а. Ошибка платежной системы при возврате депозита. Система уведомляет гостя об ошибке и предлагает обратиться в службу поддержки.

## Успех
Бронь отменена, столик свободен для бронирования, депозит возвращен согласно установленным правилам. Гость получил SMS об отмене.

## Неуспех
Бронь не отменена или депозит не возвращен. Система уведомляет гостя о возникшей ошибке.
