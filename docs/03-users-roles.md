# 3. Пользователи
1) Гость: 
    Цель - быстро забронировать столик.
    Действия: выбор стола, оплата депозита, подтверждение.
    Права: просмотр своих броней, оплата.
2) Хостес: 
    Цель - управление залом. 
    Действия: просмотр броней, отмена прихода, создание броней.
    Права: редактирование броней.
3) Управляющий: 
    Цель - контроль работы ресторана.
    Действия: просмотр аналитики, управление схемой зала.
    Права: полный доступ к настройкам ресторана.
4) Платежный сервис: 
    Цель - проведение транзакций.
    Действия: списание и возврат депозита.
