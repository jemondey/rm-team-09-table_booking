# UC-bkdep-01. Забронировать столик для компании с депозитом
 
| Поле                     | Значение                                                        |
|--------------------------|-----------------------------------------------------------------|
| Основное действующее лицо| Гость                                                           |
| Другие действующие лица  | Платежный сервис, SMS-шлюз, кассовая система                    |
| Предусловия              | Ресторан и время выбраны, в брони 6 гостей или больше           |
 
## Основной сценарий
1. Гость выбирает ресторан, дату, время, столик, количество гостей.
2. Система информирует о депозите
 
## Альтернативные сценарии
1а. Отмена брони: депозит возвращается, система снимает бронь со стола.

 
## Исключения
7а. Оплата не прошла: система уведомляет гостя, происходит повторная оплата.
7б. Стол занят: оплата не ппроходит, деньги остаются у гостя, система предлагает выбрать другой стол.
